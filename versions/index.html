Classic Daggerfall — the 1996 original

The original DOS release is a single-player game. A website running it in a DOS emulator makes it accessible online, but does not add multiplayer.

Daggerfall Unity — a desktop reimplementation

Daggerfall Unity is a separate engine project with its own installation, mod ecosystem, and save behavior. A multiplayer extension for that project is not automatically compatible with this browser client.

DFO Online — the browser project

The upstream JavaScript/WebGL2 project provides the basis for our self-hosted browser client and multiplayer services. Original game data is still required. We retain its license and Daggerfall Unity acknowledgments.

What does dfoonline refer to?

The unspaced search term dfoonline is used here to explain DFO Online, the upstream browser multiplayer project. Our domain, daggerfall.online, hosts an independent integration. Similar names do not make the services, accounts or saved progress interchangeable.

Why the names keep changing

The upstream documentation records Daggerfall JavaScript → Daggerfall Enhanced (13 September 2026) → Daggerfall Online (27 September) → DFO Online (11 October). These are rename dates, not four release dates.

Our domain is daggerfall.online. We are an independent community site, not a replacement official address for the upstream team.
