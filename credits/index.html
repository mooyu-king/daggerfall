Browser engine and multiplayer source: Lattymoy/daggerfall-js-source. Our initial checkout is 1d7655d52975572a4d47731f7eab217658ce3d14. Local community integration changes are separate from the upstream release.

Daggerfall Unity

The upstream project derives game logic and format knowledge from Daggerfall Unity, by Interkarma and contributors. Its copyright notice accompanies the MIT license.

Original game and third-party assets

The Elder Scrolls II: Daggerfall is the original game by Bethesda. Players provide its files. Third-party modifications included upstream may carry separate notices; the full upstream source and license records must be retained and reviewed before public distribution.

Website artwork

The doorway illustration on this website is decorative vector artwork created for the site. It is not a game screenshot and does not depict verified gameplay. The original gate-and-dagger logo identifies this independent website and is also used as its browser icon. It is not an official Elder Scrolls or upstream project logo.
