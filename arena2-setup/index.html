Find ARENA2

With the Steam edition installed, use Steam's Browse local files command. Look for DF/DAGGER/ARENA2 within the installation. Installation locations vary, so use the actual folder rather than copying someone else's full disk path.

The folder contains the game's data files, including ARCH3D.BSA, BLOCKS.BSA, and MAPS.BSA. Select the folder containing those files, not just the launcher or a shortcut.

Import on a computer

Open the game client and use its folder selection control. Grant access only to the game folder you intend to use. The original files are read on your device; account information and cloud saves are separate online features.

Import on mobile

Use the ZIP import option if the client offers it. Keep the archive intact and retain the original filename extensions. Do not assume that a phone supports desktop folder selection.

If the system file picker does not open inside the embedded game, open the client as a full page and retry. Mobile import, touch controls, and sustained play still need device testing.

When an import fails

An empty folder, an incomplete download, a corrupt ZIP, and insufficient storage require different fixes. Read the client's error before trying again.

  • Wrong folder: return to the picker and select ARENA2 itself.
  • Missing files: verify or reinstall your original game through its legitimate source.
  • Damaged archive: extract or rebuild it locally from your valid copy.
  • Storage failure: preserve existing saves before making space; avoid private browsing.
